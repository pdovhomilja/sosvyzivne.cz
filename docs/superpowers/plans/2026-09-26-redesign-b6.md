# Redesign B6 "Svítání" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the public frontend of sosvyzivne.cz with the approved B6 design and add the content pages Google Ad Grants needs, without touching backend, CMS or admin.

**Architecture:** New design tokens are added next to the existing ones in `app/globals.css`; new presentational components live in `components/site/`; static page content lives in typed data files in `lib/content/`; pages under `app/[locale]/` compose those. **Tech Stack:** Next.js 16 (App Router, `app/[locale]`), React 19, next-intl 4 (cs only, `localePrefix: "as-needed"`), Tailwind CSS 4 (`@theme` tokens), Prisma 7, `qrcode`, pnpm. New dev deps: `vitest`, `linkinator`, `puppeteer-core`.

## Global Constraints

- Czech copy only; typographic quotes „…“, non-breaking spaces not required.
- Fonts: Hanken Grotesk 400/500/600/700 + Instrument Serif italic, both via `next/font/google` with `subsets: ["latin", "latin-ext"]`. No other font families on public pages.
- Accent rule: max one `<Accent>` (italic serif) phrase per heading; max one `<Highlight>` per page (homepage hero only).
- Colours only via tokens: `plum #3B1C29`, `plum-2 #5A2D3D`, `rose #A8454D`, `rose-2 #B45658`, `honey #F5D7A8`, `cream #FBF3EA`, `sand #F3E5D4`, `wine #2A1720`, `wine-muted #6A4B55`. Existing tokens (`primary`, `ink`, `surface`, `border`, `accent`, …) stay untouched for admin.
- Radii: cards 24px (`rounded-3xl` → set `--radius-3xl: 1.5rem`), buttons/chips `rounded-full`, photo frames 6px.
- All text WCAG AA. No text on photos without a scrim.
- Org facts only from `lib/org.ts` (`ORG`); never hard-code IČO, phone, account, address in components.
- Photos: only white European people, candid; team photos are the real portraits in `public/images/site/team/`. Never a stock photo presented as Lenka or a team member.
- No disabled/placeholder controls; every link resolves (spec §7).
- Unconfirmed claims wrapped in `<Verify>`; live production (`VERCEL_ENV === "production"`) must throw if any render.
- Canonical host is the apex `https://sosvyzivne.cz` (default for `NEXT_PUBLIC_SITE_URL`).
- Admin (`app/[locale]/(admin)`, `(auth)`), `components/admin`, `components/cms`, `components/ui`, Prisma schema, server actions: do not modify (except `components/ui` imports removed from public pages).

## Review Focus

1. **Narrow phones (320 px) with long Czech words** ("Vymáhání neplaceného výživného", IČO strip): nothing may overflow horizontally. Pinned by the overflow check in `scripts/screenshots.mjs` (Task 1) run in Task 15 at 320/390/768/1440.
2. **Database down or empty**: homepage, blog teasers, endorsements, FAQ and sitemap must still render (HTTP 200) with the CMS sections hidden. Pinned in Task 15 Step 3 (start with an unreachable `DATABASE_URL`).
3. **Unverified claim reaching live site**: `<Verify>` in live production must fail loudly, but must render on preview so Lenka can review. Pinned by unit tests in Task 2.
4. **Nav/footer link to a route that does not exist** (easy to add in data, easy to miss): pinned by `lib/site/nav.test.ts` (Task 3) + `pnpm check:links` (Task 15).
5. **JavaScript disabled or blocked (crawler, reviewer)**: the mobile menu must still open and list all nav links. The menu is a `<details>` element, pinned by the no-JS check in `scripts/screenshots.mjs` (Task 1, used in Task 5 and 15).

```js
// Usage: pnpm shots -- / /o-nas   (server must run on BASE, default http://localhost:3000)
import puppeteer from "puppeteer-core";
import fs from "node:fs";

const BASE = process.env.BASE ?? "http://localhost:3000";
const CHROME = process.env.CHROME_PATH ?? "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome";
const WIDTHS = [320, 390, 768, 1440];
const paths = process.argv.slice(2).filter((a) => a !== "--");
if (!paths.length) paths.push("/");
fs.mkdirSync("screenshots", { recursive: true });

const browser = await puppeteer.launch({ headless: true, executablePath: CHROME });
let failed = false;
for (const p of paths) {
  for (const width of WIDTHS) {
    const page = await browser.newPage();
    await page.setViewport({ width, height: 900, deviceScaleFactor: 1, isMobile: width < 768 });
    await page.goto(BASE + p, { waitUntil: "networkidle0" });
    const overflow = await page.evaluate(() => {
      const w = document.documentElement.clientWidth;
      return [...document.querySelectorAll("body *")]
        .filter((e) => { const r = e.getBoundingClientRect(); return r.width > 0 && r.right > w + 1 && !e.closest("[data-overflow-ok]"); })
        .slice(0, 5).map((e) => `${e.tagName}.${e.className}`.slice(0, 80));
    });
    if (overflow.length) { failed = true; console.error(`OVERFLOW ${p} @${width}:`, overflow); }
    const name = (p === "/" ? "home" : p.replace(/\//g, "_").replace(/^_/, "")) + `-${width}.png`;
    await page.screenshot({ path: `screenshots/${name}`, fullPage: width <= 1440 && width > 390 ? true : false });
    await page.close();
  }
  // No-JS check: mobile menu (<details data-mobile-menu>) must contain every nav link.
  const page = await browser.newPage();
  await page.setJavaScriptEnabled(false);
  await page.setViewport({ width: 390, height: 844, isMobile: true });
  await page.goto(BASE + p, { waitUntil: "load" });
  const links = await page.$$eval("[data-mobile-menu] a", (as) => as.map((a) => a.getAttribute("href")));
  if (links.length < 5) { failed = true; console.error(`NOJS ${p}: mobile menu has ${links.length} links`); }
  await page.close();
}
await browser.close();
if (failed) process.exit(1);
console.log("shots ok:", paths.join(" "));
```

type Variant = "plum" | "glass" | "cream" | "outline-cream";
const styles: Record<Variant, string> = {
  plum: "bg-plum text-[#FFF6EC] border-plum hover:bg-[#27111B]",
  glass: "bg-white/55 text-plum border-plum/35 backdrop-blur hover:bg-white/80",

  "outline-cream": "bg-transparent text-cream border-cream/50 hover:bg-white/10",
};

export function Button({ href, variant = "plum", className, children }: { href: string; variant?: Variant; className?: string; children: React.ReactNode }) {
  const cls = cn(
    "inline-flex min-h-[50px] items-center justify-center gap-2 whitespace-nowrap rounded-full border-[1.5px] px-6 text-base font-semibold transition-colors focus-visible:outline-3 focus-visible:outline-offset-3 focus-visible:outline-[#2F4E8C]",

}

import { notFound } from "next/navigation";
import type { Metadata } from "next";
import { setRequestLocale } from "next-intl/server";
import { SERVICES, getService } from "@/lib/content/services";
import { ServiceArticle } from "@/components/site/ServiceArticle";
import { SiteHeader } from "@/components/site/SiteHeader";

export const dynamicParams = false;
export function generateStaticParams() { return SERVICES.map((s) => ({ slug: s.slug })); }

export async function generateMetadata({ params }: { params: Promise<{ slug: string }> }): Promise<Metadata> {
  const s = getService((await params).slug);
  return s ? { title: `${s.title} – SOS výživné`, description: s.lead } : {};
}

export default async function Page({ params }: { params: Promise<{ locale: string; slug: string }> }) {
  const { locale, slug } = await params;
  setRequestLocale(locale);
  const service = getService(slug);
  if (!service) notFound();
  return (<><SiteHeader /><ServiceArticle service={service} /></>);
}
